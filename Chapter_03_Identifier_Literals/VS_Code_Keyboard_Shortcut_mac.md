# Visual Studio Code Keyboard Shortcuts — macOS (Default)

> Last updated: 2026-05-09  
> VS Code version: Default keybindings (macOS)

---

## General

| Shortcut | Action |
|----------|--------|
| `Cmd + Shift + P` | Command Palette |
| `Cmd + P` | Quick Open (Go to File) |
| `Cmd + Shift + N` | New Window |
| `Cmd + W` | Close Window / Editor |
| `Cmd + ,` | Open Settings |
| `Cmd + K` `Cmd + S` | Open Keyboard Shortcuts |
| `Cmd + K` `Cmd + T` | Select Color Theme |
| `Cmd + Shift + R` | Open Recent Folder |
| `Cmd + 0` | Focus Sidebar |
| `Cmd + 1/2/3` | Focus into Editor Group 1/2/3 |
