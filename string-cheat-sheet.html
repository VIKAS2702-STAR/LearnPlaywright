💡 Quick Tips

  • 🔹 slice() vs substring(): slice accepts negatives, substring doesn't
  • 🔹 substr() is deprecated - use substring() or slice()
  • 🔹 replace() only replaces first match (use replaceAll() or regex with /g)
  • 🔹 match() returns array for /g, or match object without /g
  • 🔹 search() always returns index, unlike match()
  • 🔹 indexOf() and includes() are case-sensitive
  • 🔹 localeCompare() is best for sorting strings alphabetically
  • 🔹 Strings are immutable - all methods return new strings, don't modify original
  • 🔹 at() is the modern way to get chars (supports negative indexing unlike charAt)
  • 🔹 String.raw is great for file paths: String.raw`C:\Users\name`
